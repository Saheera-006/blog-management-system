# Blog Management System

A simple full-stack Blog Management System developed during the Codomax Digital Solutions Full Stack Development Internship.

## Features

- Home page
- Add Blog
- View Blogs
- Edit Blog
- Delete Blog
- Form Validation
- Responsive Design
- Animations and Hover Effects
- REST API integration

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Fetch API
- Git
- GitHub

## Project Structure

public/
- index.html
- blog.html
- style.css
- script.js

server.js
package.json

## How to Run

1. Install Node.js
2. Open the project folder
3. Run:

npm install

4. Start the server:

node server.js

5. Open:

http://localhost:3000
